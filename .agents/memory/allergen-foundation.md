## Rule

The initial allergen feature is a visibility aid only. A reviewed mapping with no selected allergens means none of the fixed nine tracked allergens; missing or unreviewed mappings remain unknown. Keep the derived run footprint separate from the existing manually entered run allergen and sequencing warnings.

Do not use the footprint to block production, confirm cleaning, release QC holds, or make regulatory or certified food-safety claims without a separate owner decision.

**Why:** The first increment was intentionally limited to ingredient mapping and incomplete-safe run visibility; it must not imply QC release or replace established manual sequencing behavior.

**How to apply:** When extending allergen tracking, preserve explicit review state and unknown coverage. Treat changes to run labels, sequencing, cleaning, or release gates as separate scope requiring approval.
