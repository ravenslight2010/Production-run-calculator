---
name: Run to Time operator policy
description: Owner-approved target-time semantics and reset shortcut for Dough and Crust operators.
---

Run to Time refers to today's local target. Once that clock time has arrived, it is reached; do not silently reinterpret it as tomorrow.

**Why:** The owner explicitly chose reached-today behavior when correcting the operator time-entry control.

**How to apply:** Keep future same-day targets available, but show zero remaining for current or past targets.

The reset shortcut should restore the standard 7:15 PM target, not copy the current clock time.

**Why:** The owner requested a standard-target reset instead of the proposed Set to now shortcut.

**How to apply:** Preserve this distinction when changing time-entry controls; current-time actions are not interchangeable with restoring the default.
