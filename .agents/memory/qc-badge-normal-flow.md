name: QC badge placement
description: The import-review count badge must remain visible without covering app content.
---

Keep the counts-only QC import-review badge in normal document flow, not as a fixed overlay that can cover run controls or page content. Preserve the review workflow and its checks; this is a placement decision, not a reason to hide or remove the badge.

**Why:** The fixed badge overlapped content at tablet widths, and the user approved the narrow layout fix.

**How to apply:** When changing the app shell or badge placement, retain normal-flow rendering and verify desktop, phone, tablet portrait, and tablet landscape. Do not remove review checks to address a visual overlap.
