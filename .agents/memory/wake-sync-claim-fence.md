---
name: Wake sync claim fence
description: Foreground wake auto-track claims must wait for a monotonic reconciliation acknowledgment without deadlocking same-tick dough claims.
---

The foreground reconciliation acknowledgment is the safe boundary for resuming automatic production claims. It must be monotonic and distinguish the current wake from a stale recovery notice; once that boundary has passed, queued claims from the same visible cadence must not wait on the local sync write generated by an earlier claim.

**Why:** A screen wake can release the UI fence and trigger a dough cadence in the same React render. A fixed timeout either drops valid claims or allows stale hidden-time claims, while waiting on every subsequent local push can serialize away the second claim in the same tick.

**How to apply:** Keep the browser evidence tied to the acknowledgment attribute and assert the actual claim channels plus persisted counters. Preserve the production fence before acknowledgment; after acknowledgment, let the server-side claim base/rebase logic handle the queued same-tick mutations.
