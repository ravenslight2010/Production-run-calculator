---
name: Follow-up task scope
description: The user's preference for keeping related investigation, implementation, and verification together.
---

Keep work for the same user outcome in one owning task. Do not turn implementation steps, regression tests, or verification phases into separate follow-up tasks. Asking to investigate further does not mean the user has rejected a fix.

**Why:** The user canceled tasks after follow-up suggestions proliferated and clarified that further investigation was not a refusal to make the fix.

**How to apply:** Propose a separate task only when it has a genuinely independent user outcome or the user explicitly defers it; otherwise finish the related work together.
