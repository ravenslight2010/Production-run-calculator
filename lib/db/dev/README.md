# Development identity-migration repair

The supported development and CI schema commands convert the 39 legacy serial
generators to `GENERATED BY DEFAULT AS IDENTITY` before invoking Drizzle. This
ordering prevents Drizzle from colliding with an existing serial sequence.
The conversion preserves rows, sequence ownership and grants, issued counters,
and explicit IDs beyond the previous high-water mark. Already-converted columns
are skipped without resetting their counters.

`restore-serial-generators.sql` is a retained historical **development**
rollback for the original serial schema, not a deployment migration. Do not run
it against the reconciled schema without a fresh review: newer conversion
targets were added after that rollback was written. Never connect it to
production, the deployment build, server startup, or regular schema pushes.

The normal commands are:

```sh
pnpm --filter @workspace/db run push-force
pnpm --filter @workspace/db run test:serial-to-identity
```

The regression command uses disposable, loopback-only databases. It covers
conversion before Drizzle, reruns, existing and explicit IDs, advanced
empty-table counters, the newer master-data and freezer-correction tables,
sequence grants, unexpected-configuration rollback, and identity drift checks.
Its historical command name is retained for compatibility.

A successful disposable conversion is not proof that Replit Publish can migrate
a populated production schema. Replit Publish owns managed production schema
changes; recompute and inspect its actual development-to-production diff before
publishing. Do not add deployment-build or startup-time DDL to bypass that flow.

For the bounded historical/current characterization (requires the documented
Git objects, the pinned workspace toolchain, and local PostgreSQL), run:

```sh
NODE_ENV=test node --test lib/db/migrations/branch-claims.integration.test.mjs
```

This creates source-only, frozen-lockfile historical workspaces and private
loopback database clusters. It never supplies evidence for a production Publish
conversion.
