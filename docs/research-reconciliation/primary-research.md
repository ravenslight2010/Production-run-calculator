search snippets. These are engineering inputs, **not app tests, facility policy,

## Reused research, not falsely counted as new

The deeper sync owner already independently indexed MDN Page Visibility, Chrome
Page Lifecycle, MDN SSE, PostgreSQL NOTIFY, AWS idempotent retries/backoff and
Google SRE monitoring (S06). This assessment retains that attribution rather
than repeating those sources across every domain or claiming a fresh lifecycle
benchmark. Their conclusions support server authority and measured dependency
latency; they do not establish the deployed cause of stalls.

S31 already performed immutable upstream skill/license research. It supplies
candidate evidence, not a new skill installation or paired effectiveness result.
P10 supplies a new primary accessibility/feedback boundary; it does not replace
that earlier review or establish physical-device usability.

## Decision thresholds and competing approaches

| Proposed direction | Adopt as recommendation now | Why not the larger alternative / trigger to reconsider |
|---|---|---|
| Keep one app/API/data model, selective internal seams | Yes, consistent with current constraints | New services only if measured independent workload/availability/team need outweighs auth/scope/transactions/fanout/operations cost and owner approves. |
| Improve import certainty using existing reviews/transactions | Yes, close the named real journey gap first | Universal auto-verify/Apply-all would need layout coverage, semantic deletion/conflict rules and independent verification; existing supported deterministic pipeline is safer. |
| QC advisory records and approved reference review | Yes | Gates/label claims/cross-contact scoring need qualified owner criteria; FDA overview doesn't grant them. No inference from “none of nine” to food safe. |
| Safe-state PWA update and canonical recovery | Yes | Force-reload or generic offline replay trades convenience for lost/conflicting work; demonstrate a specific missing outcome before changing ownership/cache policy. |
| Keep Gemini, evaluate local only under authorization | Yes | Synthetic smoke does not support accuracy/adoption. A second OCR runtime, training or remote provider is gated by a demonstrated gap and approved source/license/privacy/cost/resource package. |
| Reuse security/testing skills; bounded static-review pilot | Conditional | Existing suite breadth is substantial; another mandatory scan/bundle adds burden. Pilot must find real missing invariants without false positives; a task title or source grep isn't execution proof. |

No source here justifies raising pool limits, extending release timeouts, treating
unreviewed allergens as none, inferring confirmed physical output, or replacing
current production providers. Recommendations are independent engineering
conclusions; operating/legal/product/infrastructure choices remain explicitly
owner-controlled.
