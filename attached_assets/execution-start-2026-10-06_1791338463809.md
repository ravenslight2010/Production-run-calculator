## Track 2 — Stale reconnect / LWW (code-backed findings)

### What the server already does (do not reinvent)

From `protectRunValues.ts` + `sync.ts` on tip:

1. **Not blind whole-blob LWW** for the critical cases:
   - **Per-run values:** accept incoming only if `runValuesUpdatedAt` is **strictly newer**; equal/older keeps stored (blocks empty form + equal stamp wipe).
   - **Run list:** **union-merge by id** — omitted runs are kept; tombstones in `deletedItems.runs` allow real deletes.
2. **Partial PUT** materializes against baseline; snapshot fencing (`baseSnapshotId`) on partial/complete paths.
3. **Legacy unversioned complete** can be rejected (`SYNC_LEGACY_COMPLETE_WRITES=reject`) with 409 recovery.
4. **Packaging manual override** capped by **server clock** (client cannot extend forever).
5. **SSE** is process-local `Set` — Option A documents single API instance.
6. **Conflict detection** (`syncConflict.ts`) reports fields that differ after protective merge.

### Remaining risk (why “old overwrites new” can still happen)

| Risk | Mechanism | Mitigation direction |
|------|-----------|----------------------|
| **Client clock skew on stamps** | `runValuesUpdatedAt` is client-influenced; skewed device can look “newer” | Prefer server-assigned revision per field or clamp stamps to `serverTime ± skew budget`; log skew |
| **Stale offline queue replay** | Queued payload with old `baseSnapshotId` / old stamps after peer advanced | On 409 / snapshot mismatch: **rebase** (pull canonical, re-apply local intents) — never force complete overwrite |
| **Complete PUT with weak fence** | If client sends complete without valid base when policy allows | Prefer reject + recovery envelope; measure `wrote=false` / 409 rates |
| **Equal stamp + non-empty both sides** | Strictly-newer rule keeps server; client may think it won until refresh | UI: surface “server kept values” from conflict fields / merge result |
| **Non-runValues maps** | Other blobs may still be closer to LWW | Inventory which top-level keys are still replace-whole |
| **Multi-instance SSE** | Mitigated by Option A | Document min instances = 1 |
